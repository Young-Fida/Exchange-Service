# 환전 UX: 현재 구현 기준

- 모바일 우선. 데스크톱은 중앙 모바일 폭 유지. 블루 #0575E6·화이트 #FFFFFF·골드 #FDED80 유지.
- 홈은 브랜드 종이를 누르면 빛이 지나가 만원권이 드러나는 비주얼. 지구본은 제거.
- Astryx Card·Selector·NumberInput·Button·Stepper 사용. 하단은 홈·QR환전·더보기.

## 사용자 흐름
1. **금액 입력:** 수령 금액을 위에서 입력하고, 아래에서 결제 예상액을 확인한다. 수령 통화는 원화가 기본이며 양쪽 통화를 선택하고 가운데 버튼으로 스왑할 수 있다. 고시 기준일·기준율을 표시한다. 결제 통화의 최소 단위까지 올림하며 수수료는 제외한다. 하단 고정바에는 실시간 환율과 환전신청 버튼을 유지한다.
2. **최종 확인:** 받을 원화·결제할 외화·기준율·기준일의 스냅샷을 확인한다. 수정하기는 입력값을 보존하고, 확인 후 ATM 찾기에서만 신청을 생성한다. 별도 진행 단계로 세지는 않는다.
3. **ATM 이동:** TMAP POI로 선택 지역 또는 GPS 중심 1km 이내 후보를 검색한다. 가까운 최대 8개 후보의 TMAP 도보 경로를 비교하고 최대 5개를 Google 지도 핀과 목록으로 표시한다. 도보 미확인 후보는 미확인 상태로 구분한다. TMAP POI ID는 Google Place ID로 전달하지 않는다.
4. **코드 확인:** 선택 ATM 30m 이내·15초 이내 GPS 관측 조건을 유지한다. 표시를 실제 출금 완료로 간주하지 않는다.

진행 표시 자체는 금액 입력 → ATM 이동 → 코드 확인의 3단계다. 최종 확인과 로딩은 별도 단계가 아니다.

## 이동과 번역
- 입력 화면 좌상단은 홈으로 즉시 이동하며 입력을 초기화한다. 지도 뒤로가기는 원화·결제 통화 입력을 보존하고 이전 출금 요청을 해제한다. 이탈 경고·브라우저 새로고침 경고를 표시하지 않는다.
- 첫 방문은 브라우저 언어 자동 감지, 미지원 언어는 영어. 직접 선택한 언어가 우선이다.
- 국기는 로컬 SVG이며 주요 통화(한국·미국·일본·중국·대만·유로)에 표시한다. 그 외 통화는 코드 배지로 표시한다.

## 환율과 차트
- 수출입은행 실제 고시 기준율을 입력 계산과 목록에서 공유한다. JPY·IDR의 100단위를 1단위로 환산한다. 미제공 통화는 임의 환율로 대체하지 않는다. CNY와 CNH를 동일 통화로 취급하지 않는다.
- 일별: 최근 90일(3개월)의 직전·당일 고시값 변동봉. 장중 OHLC가 아니다.
- 주간: 최근 180일(6개월)의 첫·마지막·최고·최저 고시값 집계 캔들. 별도 기간 선택 버튼은 없다.
- 상승 골드·하락 블루. 날짜 선택 시 정확한 값 표시. 휴일은 관측값 없음. 일부 조회 실패는 명시한다.

## 실제 연결과 시연
- 실제 API: Google 지도 렌더링, TMAP ATM 검색·도보 경로, 수출입은행 고시환율.
- 미연결: 실제 결제·제휴 ATM 확인·출금 거래·은행 완료 통지. 고시 기준 예상액은 실제 거래 확정 금액이 아니다.
- 실제 휴대폰으로 이동하는 GPS 현장 검수는 별도로 필요하다.

## 코드 도착 상태
- 목록의 기본 미리보기는 수령 ATM 선택이 아니다. 목록·핀 또는 이 ATM에서 수령 버튼으로 확정해야 GPS 감시를 시작한다.
- 코드 해제는 도보 경로 거리가 아닌 최신 GPS와 선택 ATM 좌표의 직선거리 30m 이내, 15초 이내 관측으로 판정한다. 거리와 오차를 별도 표시한다.
- 화면 복귀 시 새 위치를 요청하고, 오래된 위치는 주기적으로 재조회한다. 시간초과·권한 거부·부정확 위치를 구분해 재확인 버튼을 제공한다.
- 도착 시 지도를 유지하며 상단 오버레이에 QR·코드를 표시한다. QR 터치 시 확대창을 연다. 작은 GPS 변화로 확대 QR을 다시 만들지 않는다. 도착 조건 이탈 시 숨긴다.
- 코드 만료 시 재발급 버튼을 제공한다. 실제 은행 출금 코드는 아닌 시연 코드다.

- GPS가 보고한 위치 오차는 안내 정보로 사용하며 20m 초과라는 이유만으로 코드를 숨기지 않는다. 실제 도착 판정은 선택 ATM과 현재 GPS의 직선거리 30m 기준이다.
- QR 표시 및 코드 확인은 거래 완료가 아니다. 은행·ATM의 검증된 거래 완료 응답이 연결되기 전에는 완료 화면으로 자동 이동하지 않는다.
- 로컬 통합 검수: tests/arrival-preview.html을 dist/qa-arrival-preview.html로 복사하여 ATM 약 20m·GPS 오차 40m를 시뮬레이션한다. 테스트용 dist HTML은 .gitignore로 배포에서 제외한다.
