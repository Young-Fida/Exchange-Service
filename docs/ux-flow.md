# 환전 UX: 현재 구현 기준

## 요구사항과 화면 역할

- 외국인 관광객이 휴대폰으로 QR을 열고 환전 신청을 시작한다. 데스크톱에서도 중앙 모바일 구성을 유지한다.
- 블루 `#0575E6`, 화이트 `#FFFFFF`, 골드 `#FDED80`, 기존 지구본과 지폐 로딩 에셋을 유지한다.
- 상단 브랜드 바는 만들지 않는다. 하단은 홈(QR 아이콘), QR환전, 더보기이며 언어 선택은 더보기에 둔다.
- Astryx Card, Selector, NumberInput, Button으로 신청 폼을 구성하고, Stepper로 실제 사용자 진행을 표시한다.
- 지도와 위치 확인을 우선한다. 진행 표시 및 QR/코드 상태는 지도 아래 스크롤 영역에 둔다.

## 진행 단계

1. **금액 입력:** 보낼 통화·금액, 받을 통화를 선택한다. 스왑과 예시 예상금액을 확인한다. 실시간 환율 및 실제 일별 환율 스파크라인은 보조 정보다.
2. **ATM 이동:** 신청 후 주변 후보를 최대 3곳 표시한다. 사용자가 ATM을 선택하고 GPS를 허용하면 내 위치에서 도보 경로를 조회한다. 지역 중심 검색과 실제 GPS를 구분한다.
3. **코드 확인:** 명시적으로 선택한 ATM에서 30m 이내, 위치 오차 20m 이하, 15초 이내의 위치 관측이 충족될 때 QR과 시연 인출 코드를 표시한다. 조건을 벗어나면 코드를 숨기고 진행 표시도 2단계로 돌아간다.

홈과 로딩은 단계로 세지 않는다. 신청 후 지폐 로딩은 처리 중 화면으로 유지한다. 코드 표시를 실제 현금 수령 또는 거래 완료로 간주하지 않는다. 실제 은행의 거래 완료 통지가 연결되기 전에는 자동 완료 단계를 만들지 않는다.

## 실제 연결과 시연의 경계

- Google 지도·ATM 검색, TMAP 도보 경로, 수출입은행 고시 환율은 실제 API다.
- 신청 화면의 예상금액은 고정 또는 직접 입력한 시연 환율을 사용한다. 실제 거래 적용 환율과 다르다는 안내를 접이식 설명으로 제공한다.
- ATM의 제휴·코드 출금 지원과 실제 출금 거래는 미연결이다. GPS 코드 잠금은 클라이언트 시연이며 은행 서버의 보안 검증을 대신하지 않는다.
- 언어 변경 시 신청 정보를 일시 보존하고 지도를 재로딩하지만, 코드 잠금 해제에는 새로운 GPS 관측이 필요하다.

## 검수

통화 우선순위, 금액 변경과 예상금액, 스왑 후 값 보존, 제출 후 2단계 전환, GPS 진입·이탈 상태 알림, 코드 숨김, 다국어, 좁은 화면의 가로 넘침, 하단 고정 버튼과 스크롤을 확인한다. 실제 휴대폰으로 이동하며 GPS를 검증하는 작업은 별도로 남아 있다.
